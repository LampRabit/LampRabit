# LampRabit: instructions for AI agents

All AI context for this project (rules, decisions, plans, progress and past sessions) lives in [.ai/](.ai/README.md).

1. Read [.ai/README.md](.ai/README.md), the index.
2. Follow [.ai/instructions/agent-rules.md](.ai/instructions/agent-rules.md): read before you work, record every piece of context the user gives in `.ai/`, and keep the index up to date.
3. Check [.ai/progress/status.md](.ai/progress/status.md) for the current state, and the decision file for the area you're changing in `.ai/context/decisions/`.

Don't add AI notes at the repository root; this file and `CLAUDE.md` only point to `.ai/`.
