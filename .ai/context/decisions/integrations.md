# Decisions: Git, doctor, CLI and MCP

The user's decisions and the reasons behind them. Don't reverse one without asking the user; when the user changes one, edit it here with the date.

- **Git** (`git.rs`, 2026-11-12): the user's own `git` CLI (never libgit2), so credential helpers and SSH keys apply; `GIT_TERMINAL_PROMPT=0` and stdin closed so nothing hangs on a prompt; user input after `--`, option-like names and `ext::` URLs refused; remote URLs and error messages lose credentials (`facts::without_credentials`). Identity changes are `--local` only. The Git tab is per project; Clone puts a repository in `www/`. `git::configure` picks LampRabit's MinGit (Runtime::Git, Windows only, in Essentials) when active, else the `git` on PATH; every git command calls it first. Clone/fetch/pull/push stream `git-progress` and can be cancelled (`git_cancel`).
- **Doctor, CLI, MCP** (2026-11-12): `doctor.rs` checks a project, `doctor_fix` reruns the checks and applies a fix through the app's own command. The running app serves `control.rs` (127.0.0.1, token in `control.json`; `LAMPRABIT_CONTROL_FILE` overrides it, as the smoke test does); `control_command` in `cmd/control.rs` maps each request onto an existing command, so add a CLI/MCP feature there, not a parallel implementation. `lamprabit` is the app run with `--cli` (cli.rs); `lamprabit mcp` is mcp.rs. Never expose settings or credentials through MCP; mark tools that change things. Settings → AI assistants: `mcp_clients.rs` adds/removes the `lamprabit` entry in assistants' MCP configs (stdio: the app with `--cli mcp`; serde_json `preserve_order` keeps their files' order; Codex's `config.toml` through `toml_edit`). On Windows the entries run a copy, `%LOCALAPPDATA%\dev.lamprabit.desktop\mcp\lamprabit.exe`, refreshed at startup (a running copy is renamed aside), because Windows won't replace a running program and an assistant keeps its MCP server running: pointing at the app blocked updates and rebuilds. The copy starts the real app (`app.txt` beside it). At startup, entries pointing elsewhere are repointed (`mcp_clients::repoint`); uninstall removes them and the copy. Claude Desktop's Store (MSIX) build reads `%LOCALAPPDATA%\Claude-Data\anthropicpbc.claude_*\claude_desktop_config.json`, never `%APPDATA%\Claude`. ChatGPT (connectors reach only internet servers) and Ollama (no MCP client) are listed with why, and `mcp::start_http` serves MCP over HTTP on `ports.mcp` (127.0.0.1, Bearer token in the config folder's `mcp-token`, Origin checked) when `mcp_server` is on.
